# T9's check follows the shared deploy lib

Apps no longer vendor the deploy lib: their gates source `${DEPLOY_LIB}/ledger.sh`, with `DEPLOY_LIB` pinned to `/srv/engineering-standards/scripts/lib/deploy` by the app's own `scripts/lib/gate/deploy-lib.sh`. `gate-image-tags.sh` followed only sources inside the app tree, so every bare `docker compose` call below that source line came out unjudged and the check went red. Reflection's browser gate moved its ledger arm below such a call to get past it, which card 717 (arm before anything runs) forbids.

The check now resolves a source path that starts with `$DEPLOY_LIB/` or `${DEPLOY_LIB}/` against `scripts/lib/deploy` of the standards clone the check itself is running from, but only when the file holding that source line either assigns `DEPLOY_LIB` nowhere or assigns it only the pinned path. Any other assignment in that file (to its own vendored copy, a `:=` default, a `read`) leaves the line unjudged, because the gate would source a different file than the one the check would read. Apps run the check from `/srv/engineering-standards`, the same clone the pin names, so the file read is the file the gate sources. An assignment made in another file the gate sources is not weighed; the app helper that sets the pin is such a file, and it also carries a test seam that may point elsewhere.

A followed file is accepted only when its fully resolved path (`readlink -f`, so a symlink inside the lib counts by its target) lies inside the lib's physical path (`pwd -P`). Only a path that came through `$DEPLOY_LIB/` is held to the lib; a literal path into the lib, or another variable whose rest happens to land there, is judged by the app-tree rule and stays unjudged. A copy of the check with no `lib/deploy` beside it reads no `$DEPLOY_LIB/` path at all, not even a same-named file in the app tree.

Cases 65 to 73 in `gate-image-tags-test.sh` hold each part. Deleting each new guard line (or making its pattern never match) turns at least one case red; the sweep is in the PR's commit message.
